## 走入开元二十九年

公元741年，唐玄宗在位，开元盛世已历近三十年。两京与十五道连接着广阔的王朝腹地，河西、安西与北庭构成通往西域的战略空间。

这不是一个等待你从长安起兵统一的乱世。如何面对盛世之下的权力、边防与地方关系，才是这个时代的起点。

## 你扮演的不是一张国旗

人物的身份决定了他能看见什么、掌握什么，又必须向谁负责。《国运》围绕人物与国家的关系展开：身居朝廷与统领一方，拥有不同的处境，也面临不同的抉择。

忠于朝廷、举兵反叛、割据自立，或暂时观望——你希望走向哪条道路？人物与身份内容仍在持续完善，可选角色及权限以当前剧本为准。

## 战争发生在舆图之上

地图不只是背景，而是观察局势与下达军令的主要界面。

- **查看山河**：缩放、拖动舆图，选择地区，了解地形、控制者与驻军。
- **组织军团**：选择军队、规划路线，在行军与交战中关注补给和目标。
- **掌握时机**：暂停思考，或调整时间速度，让局势继续推进。
- **观察天下**：切换政治、军事、补给等地图模式，从不同角度判断形势。

城池易手、地区失守，改变的不只是数字，也是地图上的控制权与边境。

## 经营一方，也影响天下

战争之外，内政、军府、外交、制度与决策同样重要。钱粮支撑军队，地方经营影响长远实力，而政治选择决定你与朝廷及其他势力的关系。

**你做出的不是一次选择，而是另一个历史。**
